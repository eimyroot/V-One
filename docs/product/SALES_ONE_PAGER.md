# VOODOO One

## Governed AI Operations Control Plane

VOODOO One gives organizations a controlled path from an AI agent request to a provable execution result.

### Core workflow

`request → policy/review → approved execution → evidence receipt`

### Customer value

- see what agents want to do before effects occur,
- separate requesters from approvers,
- require two-person approval for production,
- stop execution globally during an incident,
- preserve an audit trail and cryptographic receipt chain,
- operate local or sensitive workloads without exposing raw secrets in the UI.

### Initial pilot use cases

- governed code and configuration changes,
- approval of AI-generated operational actions,
- controlled local validation and artifact generation,
- compliance evidence for autonomous workflows,
- security review of agent capabilities and effects.

### Delivery model

The current development baseline can enter a controlled pilot only after customer-specific
acceptance. Production connectors and enterprise identity remain separate security gates.
